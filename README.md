## Nội dung thực hành

Bài thực hành tìm hiểu và cài đặt các mẫu thiết kế (Design Patterns) thuộc nhóm Creational Design Patterns bằng ngôn ngữ C#.

Các mẫu thiết kế được triển khai:

- Abstract Factory Pattern
- Builder Pattern
- Factory Method Pattern
- Prototype Pattern
- Singleton Pattern

Ngoài ra, project có các ví dụ áp dụng thực tế cho từng mẫu thiết kế như quản lý nhân viên bán hàng, hóa đơn, báo cáo, lô hàng và cơ sở dữ liệu.

- Nền tảng: .NET
